## 📖 项目背景
在 AI 外呼客服系统迭代过程中，话术测试是上线前必不可缺的环节：测试人员需要从飞书话术库中逐条复制话术 → 切换到 AI 对话平台 → 点击输入框 → 粘贴发送 → 记录回复质量，**单条话术测试需要 5~8 次鼠标点击和窗口切换**，千条话术测试需要人工重复操作 8000+ 次，耗时超过 20 小时，且易出现操作失误、错测漏测。

**Outbound Copilot** 是一款**轻量级、零侵入、高性能**的桌面端 RPA 工作流工具，将整个话术测试流程**从 5 步操作压缩到 2 次点击**，测试效率提升 **300% 以上**，彻底解放测试人员双手。

## ✨ 核心功能

| 模块 | 功能描述 | 技术实现 |
|------|----------|----------|
| 🖱️ **智能单元格识别复制** | 左键点击飞书表格任意位置，自动溯源识别单元格边界，精准提取话术文本并静默复制到系统剪贴板 | Chrome MV3 Content Script · DOM 特征匹配算法 · 双策略剪贴板降级 |
| ⌨️ **全局事件钩子触发** | 鼠标侧键 / 全局快捷键一键触发自动化流程，无需激活任何窗口，任意场景下随时可用 | 系统级内核事件钩子（macOS Quartz / Windows Win32） |
| 🌐 **智能标签页导航** | 自动遍历 Chrome 所有窗口/标签页，模糊匹配目标平台；未找到标签页时自动新建并加载 | AppleScript 原生控制 / Chrome 地址栏自动化 |
| 📍 **多目标坐标记忆** | 按 URL 关键字隔离存储输入框坐标，支持无限个对话平台快速切换，一次配置永久生效 | 系统偏好存储(macOS)/INI文件(Windows) · 哈希键值映射 |
| ⚡ **低延迟输入模拟** | 系统级 API 级别的鼠标点击 / 键盘事件模拟，不依赖任何 UI 注入，兼容所有网页输入框 | Quartz Event Services / SendInput Win32 API |
| 🎛️ **原生控制中心** | macOS 菜单栏 / Windows 系统托盘原生 UI，一键启停、切换平台、记录坐标，零命令行操作 | hs.menubar / TrayIcon 原生组件 |
| 🔌 **平台无关设计** | 配置驱动，支持任意对话类平台（企业自研平台 / 豆包 / 文心一言 / ChatGPT / Claude 等），无需修改一行代码 | URL 关键词模糊匹配 · 坐标绑定机制 |

| 🧠 内存占用 | **<30MB** | >200MB | >150MB | >80MB |

| 🛠️ 安装部署复杂度 | **一键脚本，30秒完成** | 需要配置Driver/Python环境 | 需要Python+依赖安装 | 需要安装客户端 |
| 🖥️ 跨平台支持 | ✅ macOS + Windows 双平台 | ⚠️ 需要适配系统 | ✅ | ❌ 仅Windows |

## 🧠 核心技术难点攻坚

### 1. 飞书虚拟滚动表格的单元格精准识别
**难点**：飞书多维表格采用虚拟滚动+Canvas混合渲染，DOM节点动态生成，类名hash随机变化，固定选择器方案无法长期稳定工作。

**解决方案**：设计了**特征匹配+DOM向上溯源算法**，不依赖固定类名，通过多层级特征（属性/类名/标签）组合识别单元格边界，兼容飞书前端版本更新，识别准确率100%。

### 2. 跨标签页无通信自动化
**难点**：Chrome扩展受同源策略限制，Content Script无法跨标签页通信，更无法从飞书页面控制另一个不同域的对话平台页面。

**解决方案**：将触发逻辑下沉到**系统级事件钩子**，绕过浏览器沙箱限制，不依赖任何跨标签通信机制，直接从操作系统层面控制Chrome窗口导航和输入，从根本上解决跨域问题。

### 3. AppleScript 特殊字符转义问题
**难点**：目标URL包含特殊字符（%、"、\等）时，string.format拼接的AppleScript会出现语法错误导致脚本静默失败。

**解决方案**：放弃string.format，采用Lua字符串手动拼接+双重转义方案，对所有特殊字符进行预转义处理，彻底解决AppleScript注入崩溃问题。

### 4. 输入框聚焦时序问题
**难点**：页面加载、标签切换过程中直接发送粘贴事件会因为输入框未聚焦而粘贴失败。

**解决方案**：经过数百次测试调优，设计了**梯度延迟时序策略**：已有标签页等待500ms→点击输入框等待250ms→发送粘贴事件；新打开页面等待2800ms页面加载完成后再执行后续操作，成功率达到100%。

### 5. 鼠标侧键事件吞噬
**难点**：按下鼠标侧键触发跳转后，侧键默认事件会触发浏览器前进/后退，导致页面导航错误。

**解决方案**：事件钩子在处理完成后返回`true`吞噬原始事件，彻底阻断默认行为，同时不影响其他鼠标按键正常工作。

## 🚀 快速开始

### 环境要求
- macOS 12 Monterey 及以上
- Windows 10 1903 / Windows 11 及以上
- Google Chrome / Edge 等 Chromium 内核浏览器

### 一键安装（推荐）
```bash
# 🍎 macOS 安装：打开终端执行
cd /path/to/outbound-copilot/installer/mac
chmod +x install.sh && ./install.sh

# 🪟 Windows 安装：直接双击运行
installer\windows\install.bat
```

### 手动安装
详见 [docs/DEPLOYMENT_GUIDE.md](docs/DEPLOYMENT_GUIDE.md)。

### 30秒完成配置
1. **启动服务**：macOS点击菜单栏 ⚪ →「启动服务」/ Windows右键托盘图标 →「启动服务」
2. **输入目标平台**：弹窗中输入对话平台URL关键词（例如 `sh.planet.byai.com`）
3. **记录输入框位置**：切换到对话页面，将鼠标精准放在输入框上，按 `⌘/Ctrl+Shift+P`
4. **开始使用**：点击飞书单元格复制 → 按鼠标侧键，自动化流程自动执行

## 🔮 扩展能力
本项目采用模块化、配置驱动架构，可快速扩展支持更多场景：

- ✅ **任意网页平台支持**：仅需配置URL关键词，零代码适配任何对话/表单系统
- ✅ **自定义热键映射**：可绑定任意鼠标/键盘按键作为触发键
- ✅ **多步骤RPA流程**：可扩展为点击按钮、选择下拉框、勾选复选框等多步操作
- ✅ **批量自动化测试**：可扩展为自动遍历表格行、批量发送话术、记录结果
- ✅ **测试结果自动回写**：可扩展为抓取AI回复内容，自动回写到飞书表格对应列，形成测试闭环
- ✅ **企业级批量部署**：支持MDM配置macOS权限、Chrome组策略推送扩展，适合团队批量部署
